🎯 THEME FLOW
═══════════════════════════════════════════════════════

themeConfig.js (Define colors)
       ↓
   [Export theme object]
       ↓
Components import theme
       ↓
Use theme in style props
       ↓
  Consistent design!

Example:
  import themeConfig from '../theme/themeConfig';
  
  <div style={{ 
    backgroundColor: themeConfig.colors.accent 
  }}>
