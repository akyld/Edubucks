🎨 CHANGE COLORS IN 30 SECONDS
══════════════════════════════════════════════════════════════

1. Open: src/theme/themeConfig.js

2. Find this:
   ┌─────────────────────────────────────┐
   │ colors: {                           │
   │   primary: '#000000',    // Black   │
   │   accent: '#FF7A00',     // Orange  │
   │ }                                   │
   └─────────────────────────────────────┘

3. Change to your colors:
   ┌─────────────────────────────────────┐
   │ colors: {                           │
   │   primary: '#1E40AF',    // Blue    │
   │   accent: '#3B82F6',     // Sky     │
   │ }                                   │
   └─────────────────────────────────────┘

4. Save and watch the entire site update! ✨

🆘 TROUBLESHOOTING
══════════════════════════════════════════════════════════════

Problem: npm command not found
Solution: Install Node.js from nodejs.org

Problem: Port already in use
Solution: Vite will auto-use next port

Problem: Changes not showing
Solution: Hard refresh (Ctrl+Shift+R)

Problem: Build errors
Solution: Delete node_modules, run npm install

Problem: Theme not applying
Solution: Check import path to themeConfig.js
